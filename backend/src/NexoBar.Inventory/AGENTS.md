# Inventory

Lee [Inventory](../../../docs/inventory/README.md) para Estado, operaciones, Historia, migraciones y pendientes. Allí viven `null != 0`, revisiones, Conteo/Reconciliación, saldos negativos y separación respecto de ventas.

Para cambiar autorización o resolución de actor, añade [Identity y autorización](../../../docs/identities-and-capabilities/security.md). Para cambios verticales, añade [Inventory frontend](../../../docs/inventory/frontend.md).
