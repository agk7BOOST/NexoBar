# Catalog

Lee [Catalog](../../../docs/catalog/README.md) antes de cambiar Product, comandos o configuración de preparación.

- Para `OrderConfirmationCatalog`, snapshots, Price Change o concurrencia con Confirmation, lee [colaboración transaccional](../../../docs/catalog/confirmation-collaboration.md).
- Para referencias a destinos, consulta solo la capacidad de [OperationalConfiguration](../../../docs/operational-configuration/README.md).
- Para lookup de nombres consumido por Preparation/Delivery, consulta el contrato de lectura del consumidor afectado: [Preparation](../../../docs/order-operations/preparation.md) o [Delivery](../../../docs/order-operations/delivery.md).
- El resto de la semántica de Preparation no es contexto de una tarea exclusivamente de Catalog. Frontend asociado: [catalog/AGENTS.md](../../../frontend/src/catalog/AGENTS.md).
